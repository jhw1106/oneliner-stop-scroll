# One Line to Stop the Scroll

A tiny Node program that writes one original line of text — written to make a stranger stop scrolling and smile — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), validating that it is a single non-blank line of 1–200 characters and at most 200 bytes, and failing loudly otherwise.
